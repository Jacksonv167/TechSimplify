How to Take a Screenshot on Windows

Learn simple ways to capture your screen on a Windows computer using keyboard shortcuts and built-in Windows tools.

What Is a Screenshot?

A screenshot is an image of what is currently displayed on your computer screen. Screenshots are useful when you want to save information, show someone a problem, or keep a copy of something displayed on your screen.

Windows provides several simple ways to take screenshots without installing additional software.

1. Use the Print Screen Key

One of the simplest ways to capture your entire screen is to use the Print Screen key, which may appear on your keyboard as PrtSc, PrtScn, or a similar abbreviation.

Press the Print Screen key to capture the current screen. The screenshot may be copied to your clipboard, depending on your Windows settings.

You can then open an application such as Paint and press Ctrl + V to paste the screenshot.

2. Use Windows + Print Screen

You can automatically save a screenshot by pressing:

Windows key + Print Screen

Your screen may briefly dim when the screenshot is captured. Windows saves the image automatically in the Screenshots folder inside your Pictures folder.

3. Use Windows + Shift + S

Windows also provides a convenient shortcut for capturing part of your screen.

Press:

Windows key + Shift + S

The screen will dim and a screenshot toolbar will appear. You can then select the area you want to capture.

The captured image is normally copied to the clipboard, allowing you to paste it into another application.

4. Use the Snipping Tool

The Snipping Tool is a built-in Windows application that lets you capture screenshots in different ways.

To find it, open the Windows Start menu and search for Snipping Tool.

Open the application and choose the screenshot option you want to use.

5. Capture a Specific Area

If you do not want to capture the entire screen, you can capture only a specific section.

Press Windows + Shift + S and select the area you want to capture with your mouse.

This is useful when you only need to save part of a webpage, application, document, or image.

6. Capture an Entire Window

Sometimes you may want to capture only the window that is currently active instead of the entire desktop.

On supported Windows keyboards, you can use:

Alt + Print Screen

This captures the active window rather than everything displayed on your screen.

7. Edit Your Screenshot

After taking a screenshot, you may want to crop it, draw on it, highlight something, or add other simple changes.

Windows tools such as Snipping Tool and Paint can be used for basic editing.

8. Where Are Windows Screenshots Saved?

Screenshots captured using Windows + Print Screen are commonly saved in the Screenshots folder.

You can usually find this folder by opening:

Pictures → Screenshots

Screenshots captured using other methods may instead be copied to the clipboard until you paste or save them.

9. How to Paste a Screenshot

If a screenshot has been copied to your clipboard, open the application where you want to place it.

Then press:

Ctrl + V

The screenshot should appear in the application if it supports image pasting.

10. How to Take a Screenshot on a Laptop

Some laptops use a Print Screen key together with another keyboard key. The exact shortcut can vary depending on the laptop manufacturer and keyboard design.

If the normal Print Screen shortcut does not work, try Windows + Shift + S or open the Snipping Tool.

11. How to Take a Screenshot of a Webpage

You can use Windows screenshot shortcuts to capture content visible in your browser.

For a specific section of a webpage, Windows + Shift + S is a convenient option because you can select the area you want to capture.

12. How to Take a Screenshot for Troubleshooting

Screenshots can be useful when asking for technical support.

For example, if you see an error message on your computer, you can capture the message and send the screenshot to someone helping you.

Before sharing a screenshot, check that it does not contain passwords, private messages, financial information, or other sensitive information.

Common Screenshot Shortcuts

  • Print Screen: Captures the screen or copies it to the clipboard depending on the setup.
  • Windows + Print Screen: Captures the screen and saves the screenshot.
  • Windows + Shift + S: Opens the screen capture selection tool.
  • Alt + Print Screen: Captures the active window on supported setups.

Frequently Asked Questions

What is the easiest way to take a screenshot on Windows?

Windows + Shift + S is a convenient option when you want to quickly select a specific area of the screen.

Where does Windows save screenshots?

Screenshots taken with Windows + Print Screen are commonly saved under Pictures → Screenshots.

Can I take a screenshot without installing an app?

Yes. Windows includes built-in screenshot shortcuts and tools, so additional software is not required for basic screenshots.

Can I screenshot only part of the screen?

Yes. Windows + Shift + S allows you to select a specific area of the screen.

Can I edit a screenshot after taking it?

Yes. You can use built-in applications such as Snipping Tool or Paint for basic editing.

Conclusion

Taking screenshots on Windows is simple because Windows provides several built-in methods.

You can use keyboard shortcuts such as Windows + Shift + S, Windows + Print Screen, or the Snipping Tool depending on what you want to capture.

Once you learn these shortcuts, you can quickly save, share, and edit screenshots whenever you need them.
